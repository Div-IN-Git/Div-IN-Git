## About Me

I am Divyanshu Swain, a software engineering and artificial intelligence builder focused on turning applied research ideas into usable engineering systems.

My work spans machine learning, computer vision, backend engineering, desktop applications, automation, and data-oriented AI pipelines. I enjoy building systems that combine a research mindset with product engineering discipline: understanding the problem deeply, designing practical architecture, and shipping tools that can be used, tested, and improved.

I am especially interested in AI systems that connect models with real-world workflows, including scientific forecasting, OCR and document understanding, surveillance intelligence, security automation, and networked interactive applications.

<summary><strong>Foresight</strong> - AI-powered Solar Flare Forecasting</summary>

Foresight is an AI-powered solar flare forecasting pipeline built around Aditya-L1 data, with a focus on scientific AI, time-series modeling, and space weather intelligence.

The project represents a research-oriented engineering system where data ingestion, temporal analysis, machine learning workflows, and forecasting outputs are treated as parts of a connected pipeline.

| Category | Details |
|---|---|
| Stack | Python, Machine Learning, Time Series, Data Engineering |
| Architecture | Data pipeline for scientific forecasting using temporal solar observation data |
| Engineering Focus | Space weather prediction, model workflow design, scientific data processing |
| Business / Research Impact | Supports research exploration in solar activity forecasting and AI-assisted space weather analysis |

</details>

<summary><strong>OCRApp</strong> - Desktop OCR and Document Reconstruction</summary>

OCRApp is a desktop OCR application using Python and Qt/PySide6 for intelligent document reconstruction, geometry-aware OCR, document processing, and automation.

The application focuses on extracting text from documents while preserving structural meaning through geometry-aware processing, making it suitable for workflows where raw OCR output is not enough.

| Category | Details |
|---|---|
| Stack | Python, Qt, PySide6, OCR, Computer Vision |
| Architecture | Desktop application with OCR engine, geometry reconstruction, document processing, and automation modules |
| Engineering Focus | Multilingual OCR, layout reconstruction, desktop UX, automation |
| Current Status | Public repository available |
| Repository Link | [Div-IN-Git/OCRApp](https://github.com/Div-IN-Git/OCRApp) |
| Business / Research Impact | Helps transform scanned or image-based documents into structured, usable text workflows |

</details>
